# B00 · Preparação da sprint

O B00 estabelece a base de integração para os lotes B01 a B18. O primeiro commit documenta os papéis e permite observar uma revisão real em uma PR pequena. O fechamento do B00 depende de evidências externas para o SHA final.

| Entrega | Aceite e contraprova |
| --- | --- |
| Checkout | Clone isolado da main remota identificada por SHA, arquivos locais preservados e instalação de desenvolvimento em Python 3.12. |
| Referência | Identificar o job cancelado, a nova tentativa, o SHA e o resultado de cada job. Uma falha na main suspende merges. |
| Cobertura | Exatamente 65 IDs de 1 a 67, com as lacunas 40 e 41. Cada ID tem um único lote e um aceite próprio. |
| Auditoria | Parecer independente sobre o commit congelado. Um SHA anterior ou critério sem aceite bloqueia o fechamento. |
| Qodo | Observar uma revisão completa no SHA. Capturar resumos, comentários e reviews, incluindo os achados anteriores. Ausência, timeout e achado aberto bloqueiam. |
| GitHub | PR obrigatória, conversas resolvidas e checks obrigatórios. O verificador usa lógica confiável e mantém credenciais privilegiadas fora dos testes da proposta. |
| Retomada | Interromper a coleta, reconstruir o estado a partir do Git e da PR e repetir sem duplicar a integração. |

A versão dos formatos, o contrato da CLI e a preservação das aprovações entram nos contratos dos lotes que alteram essas interfaces. A migração cobre pastas e exportações, e a pesquisa começa por busca textual. A execução autenticada do Claude no Mac pessoal e a avaliação semântica humana ficam pendentes de evidência específica.
